All activities in this group described by artifacts, screenshots and config files were carried out using the security onion provided by Cisco Network Academy (NETACAD)

Security Onion includes the following tools

1. Kibana from the ELK stack, for investigating alerts
2. The sguil tool to view alerts, counts and more before pivoting to other applications
3. The terminal to perform conversions, check service statuses ...
4. capME! to allow you to view a pcap transcript using a web interface
